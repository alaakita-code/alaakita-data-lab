# ALAAKITA Public Data Lab

**讓每一項數據洞見，都有可以追溯的證據。**

ALAAKITA Public Data Lab 是一套結合**公開資料分析、資料品質管理、證據檢索與研究成果展示**的互動工作室。

從資料擷取、清理與歷史比較，到文件切分、來源引用與檢索品質評估，建立可理解、可查核、可逐步擴充的資料研究流程。

目前版本：**V5.8**

## 線上體驗

- **[開啟互動研究工作室](https://alaakita-code.github.io/alaakita-data-lab/)**
- **[開啟十頁研究簡報](https://alaakita-code.github.io/alaakita-data-lab/presentation.html)**

支援 Android 手機、平板及桌機瀏覽器，採響應式網頁設計。

> **資料聲明：** 目前網站使用 DEMO 合成資料，並非即時 YouBike 官方統計或正式營運監測資料。

## 核心功能

| 功能模組 | 內容 |
|---|---|
| 研究總覽 | 資料品質、時間區間、歷史比較及研究指標 |
| 證據問答 | 搜尋公開證據片段、顯示來源並於證據不足時拒答 |
| 來源索引 | 文件分類、Chunk ID、來源網址與完整性資訊 |
| RAG 品質評估 | 透過預設測試題評估檢索命中與拒答表現 |
| 操作與架構 | 研究流程、權限設計原則、CLI 操作與 JSON／CSV 匯出 |
| 十頁研究簡報 | 互動閱讀、快速跳頁與研究成果整理 |

## 研究流程

```text
公開資料與研究文件
        ↓
資料擷取與欄位驗證
        ↓
資料清理、歷史快照與比較
        ↓
文件切分與來源中繼資料
        ↓
權限檢查與證據檢索
        ↓
來源引用、拒答與品質評估
        ↓
互動工作室與研究簡報
```

這是專案的整體研究架構。目前公開的 V5.8 網頁屬於靜態 DEMO，不會自動擷取即時 API 或執行後端 Python 程式。

## 技術設計與可信度

專案以 HTML、CSS、JavaScript 建立互動式前端，使用 GitHub Pages 提供 HTTPS 網站。

**證據檢索：** V5.8 使用字元雜湊 TF-IDF 相似度計算，並非已串接生成式大型語言模型。

**來源完整性：** 透過文件識別碼與 SHA-256 協助核對資料，但雜湊驗證不代表政府數位簽章或官方認證。

**研究品質：** 區分已知證據、未驗證假設與證據不足的問題，避免產生沒有資料支持的結論。

**權限安全：** 正式跨使用者 ACL 必須由可信任的後端執行，公開靜態網頁不適合存放機密文件。

資料情境參考：[政府資料開放平臺－YouBike 相關資料集](https://data.gov.tw/dataset/137993)。

## 使用方式

**線上體驗：** 直接使用 Android Chrome、桌機 Chrome 或 Edge 開啟網站連結，無須另外安裝應用程式。

**GitHub Pages 部署：** 將 `index.html` 與 `presentation.html` 放在同一個儲存庫根目錄，於 Settings → Pages 設定從 `main` 分支的 `/(root)` 發布。

## 後續發展

上述項目屬於後續規劃或待驗證能力，並非全部已在 V5.8 公開網站上線。
