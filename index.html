05 / IMPLEMENTATION GUIDE

操作流程與技術邊界

從零成本的本機示範，再到可選用的真正神經 Embedding 與 LLM 回答。

本機實作四階段

① 驗證來源：從 V1–V3 讀入 JSON 快照及 SQLite，核對雜湊與時間。

② 文件切分：統計與方法文件建立 Chunk ID，附上證據 ID 與權限標籤。

③ 檢索前 ACL：從可信的後端取得授權角色，只讓可見片段進入相似度計算及 LLM Prompt。

④ 檢索與審核：返回來源片段，必要時交由本機 LLM 組織答案，並執行數字及引用驗證。

正式部署需要身分驗證、資料隔離、API 存取權限、稽核記錄與模型輸出人工審查；瀏覽器角色切換不是資安隔離。

Windows CLI 指令

指令 1
py -3 v5.py demo
指令 2
py -3 v5.py ask --mode DEMO --question "近週完整率是多少"
指令 3
py -3 v5.py eval --mode DEMO

額外安裝神經 Embedding 後，使用 --method e5。

安裝並啟動 Ollama 後，使用 --llm；本地模型必須先下載，且每次生成結果都需要人工查核。

指令區可左右滑動檢視完整內容。完整安裝、LIVE 模式與排錯請參考壓縮檔內 README_V5.md。
